# Home map location recenter

Дата этапа: 30 July 2026.

## Контекст

Кнопка центрирования карты по местоположению устройства на главном экране
выполняла полный запрос свежей геолокации до движения камеры. На Android
`Geolocator.getCurrentPosition()` может ждать несколько секунд, особенно при
холодном GPS fix, поэтому кнопка визуально выглядела как зависшая.

## Решение

- Главный экран сначала центрирует карту по уже загруженной координате
  `currentUserLocationValue`.
- Свежая геолокация запрашивается после этого и обновляет центр только если
  вернула валидные координаты, отличающиеся от текущих.
- Fallback `LatLng(0.0, 0.0)` не используется как цель центрирования.
- `CustomGoogleMap` получил отдельный `centerMoveRequestId`, чтобы повторное
  нажатие работало даже при той же самой координате.

## Границы этапа

Этот этап не меняет Supabase-контракты, RPC, Storage, deep links, парковочные
данные или права записи. Изменение ограничено клиентским поведением кнопки
центрирования и внутренним контрактом custom map widget.
