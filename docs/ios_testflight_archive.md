# iOS TestFlight archive

Date: 2026-07-31.

## Scope

This stage restores a reproducible iOS archive from `main` without changing
application behavior or Supabase contracts. No production release was
submitted.

The first Xcode archive failed because `Runner.xcworkspace` referenced only
`Runner.xcodeproj`. CocoaPods had installed Google Maps and the other native
plugins on disk, but Xcode could not resolve `GoogleMaps` because the Pods
project was absent from the workspace.

## Repository configuration

- Open `ios/Runner.xcworkspace`, never `Runner.xcodeproj` or the repository
  folder.
- `Runner.xcworkspace` includes both `Runner.xcodeproj` and
  `Pods/Pods.xcodeproj`.
- `ios/Podfile.lock` pins the CocoaPods dependency graph used by the archive.
- The shared Xcode scheme contains the Flutter prepare action required by the
  current Flutter/Xcode toolchain.
- The canonical workspace `Package.resolved` pins the Swift package graph
  generated by Flutter.
- Release signing uses the team App Store profile
  `JS Truck Park App Store 2026-07-31` and Apple Distribution certificate.
  The `.mobileprovision` file and private key are Apple account assets and are
  not stored in Git.

After a fresh checkout, run:

```bash
flutter pub get
cd ios
pod install
```

If Xcode reports that `Runner.xcworkspace` changed on disk after `pod install`,
choose `Use Version on Disk` so the Pods project remains connected.

## TestFlight checklist

After App Store Connect finishes processing build 50:

1. Add the build to the internal `Dev` group.
2. Install it through TestFlight on a compatible physical iPhone.
3. Open a fresh Chottu referral link with the app terminated and while it is
   running.
4. Repeat the deferred-install referral flow with a fresh account.
5. Verify parking and shared-photo links.
6. Verify map rendering, review creation, photo upload and subscription loading.
7. Do not submit the build to App Review until the closed-test checklist passes.

## Rollback

Revert this infrastructure commit if iOS dependency resolution regresses. The
uploaded TestFlight artifact and Apple signing assets are not removed by a Git
rollback; manage them separately in App Store Connect and Apple Developer.
